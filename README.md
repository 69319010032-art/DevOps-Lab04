# FixFlow — IT Support

เว็บไซต์ตัวอย่างสำหรับแจ้งปัญหาและขอรับบริการด้าน IT ช่วยให้ผู้ใช้ดูบริการ ขั้นตอนการแจ้งปัญหา และกรอกข้อมูลเพื่อให้ทีม IT Support ติดต่อกลับได้ในหน้าเดียว

## ความสามารถ

- แสดงบริการด้านคอมพิวเตอร์ เครือข่าย และโปรแกรม/บัญชีผู้ใช้
- อธิบายขั้นตอนการแจ้งปัญหาและติดตามงาน
- มีแบบฟอร์มสำหรับกรอกชื่อ อีเมล ประเภทปัญหา และรายละเอียด
- รองรับการแสดงผลบนคอมพิวเตอร์และอุปกรณ์มือถือ

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server ใน Visual Studio Code เพื่อดูหน้าเว็บ

## หมายเหตุ

โปรเจกต์นี้เป็นหน้าเว็บตัวอย่าง แบบฟอร์มยังไม่ได้เชื่อมต่อระบบหลังบ้านหรือส่งข้อมูลจริง เมื่อกดส่งจะแสดงข้อความยืนยันบนหน้าเว็บเท่านั้น
